# 番茄钟 · Pomodoro

> 一个把记录权还给你的番茄钟。数据只存在本机，不联网、不登录、不订阅。

## 为什么会有这个东西

市面上做得好的番茄钟，计时几乎都免费，收钱的是**记录**——历史、统计、导出。

但番茄钟真正有价值的部分恰恰是记录。它回答的不是"现在几点"，是"我这周到底学了多少"。计时器遍地都是，账本不该上锁。

所以这个项目的定位不是番茄钟，是**一个带计时器的时间账本**。

## 功能

- **分科目记账**：每个番茄记下起止时间、科目、时长，可补一行备注
- **时长可配**：预设按钮 + 自定义 1–180 分钟，休息分短休/长休
- **结束只出声，不弹窗**：不抢焦点，不打断思路
- **今日**：完成番茄数、完成分钟、分科目分钟；放弃的单独列为「未完成分钟」，不并进总数
- **本周**：7 天柱状，一眼看出哪天断了
- **流水**：每一条都可见，可随时补备注
- **导出 CSV / 复制 JSON**：数据随时能拿走
- **深浅色跟随系统**
- **快捷键**：空格开始/暂停，R 放弃

## 有意不做

| 不做 | 理由 |
|---|---|
| 云同步 / 账号 | 数据在你机器上，不需要经过任何服务器 |
| 待办清单 / 任务管理 | 番茄钟一旦兼做任务管理，就变成又一个让人分心的应用 |
| 网站拦截 / App 屏蔽 | 系统自带的专注模式做得更好 |
| 月视图 / 年热力图 | 番茄数只能测"坐了多久"，测不了"学会了多少"。超过今日和本周两个视图，就是自我安慰 |
| 白噪音 | 音乐软件更合适 |

## 开发

前提：

- Node.js 18+
- Rust stable（[rustup.rs](https://rustup.rs)）
- macOS 需要 `xcode-select --install`

```bash
npm install
npm run dev      # 开发模式，改前端刷新即可
npm run build    # 打包，产物在 src-tauri/target/release/bundle/
```

技术栈：Tauri 2 + 原生 HTML/CSS/JS，**零前端框架、零运行时依赖**。前端就是 `src/` 下三个文件，改起来不需要懂 Rust。

打包体积：**4.6 MB（.app）/ 2.6 MB（.dmg）**。

架构上只有一处用了 Rust：CSV 导出调用 `save_text` 命令直接写下载目录。原因是 WKWebView 不实现浏览器的下载流程，`a[download]` 会静默失败——而这个应用的立身之本就是"记录拿得走"，不能赌。

## 发版

版本号散在四个文件里，漏改一个**不会报错**，只会让产物文件名、Cargo 元数据、界面显示三处各说各话。所以做成了命令：

```bash
# 1. 改版本号，四处都要改：
#    package.json / src-tauri/Cargo.toml / src-tauri/tauri.conf.json / CHANGELOG.md
npm run version:check    # 不一致会列出来并以退出码 1 结束

# 2. 构建
npm run build

# 3. 打 tag
git tag -a v0.1.0 -m "v0.1.0"
git push origin main --tags
```

## 数据

- 存在 WebView 的 `localStorage`，键名 `pomodoro.v1`，不离开本机
- 换电脑或重装前，用「导出 CSV」或「复制全部数据」备份
- **日界是凌晨 4 点**：学到 1 点的那一段算前一天。按自然日切会让周统计错位

## 当前限制

- 科目预设有三个（英语 / 高数 / 其他），还不能在界面里自定义
- 只有中文界面

这两条在路线图里。

## 平台支持

| 平台 | 状态 | 说明 |
|---|---|---|
| macOS | ✅ 已验证 | `npm run build` 出 `.app` 和 `.dmg` |
| Windows / Linux | ⏳ 未构建 | Tauri 支持，但 macOS 上无法交叉编译，需要 CI 或对应平台的机器 |
| Android / iOS | ⏳ 未构建 | 代码已按移动端准备好（Rust 入口拆成 lib crate 带 `mobile_entry_point`，前端补了安全区和窄屏适配）。要出包还差 Android SDK / Xcode；iOS 另需 Apple 开发者账号 |

代码结构上没有阻碍，缺的只是构建环境。
